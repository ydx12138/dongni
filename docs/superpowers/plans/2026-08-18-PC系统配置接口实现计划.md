# PC 系统配置接口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 PC 端系统配置页面接入后端存储、管理员修改、前台读取和功能开关控制。

**Architecture:** 保留现有 `handler -> service -> repository` 三层结构。Repository 负责 `setting` 表的查询和事务 upsert，Service 负责默认值、格式校验和功能开关判断，Handler 负责 DTO 绑定与统一响应。前端通过公共接口初始化配置，通过管理员接口读取和保存配置。

**Tech Stack:** Go、Gin、GORM、MySQL、Vue 3、Fetch API、现有统一响应和 JWT 中间件。
