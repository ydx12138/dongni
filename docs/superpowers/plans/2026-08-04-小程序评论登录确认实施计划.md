# 小程序评论登录确认实施计划

> **供自动化执行者使用：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐项执行。本计划使用复选框跟踪进度。

**目标：** 未登录用户发表小程序评论时，先由用户确认，再调用既有微信登录流程并继续提交该评论。

**架构：** 新增一个仅包装 `wx.showModal` 的小工具函数，它接收微信 API 对象以便在 Node 测试中模拟确认结果。文章详情页在调用 `ensureLogin()` 前检查本地 token；无 token 时先调用该工具，取消则提前返回，确认才进入现有登录和评论提交流程。

**技术栈：** 微信原生小程序 JavaScript、Node.js 内置 `node:test`、现有 `wx.login` 和 REST API。

```js
function confirmCommentLogin(wxApi) {
  return new Promise((resolve) => {
    wxApi.showModal({
      title: '需要登录',
      content: '登录后才能发表评论，是否继续？',
      confirmText: '登录',
      cancelText: '取消',
      success: (result) => resolve(result.confirm === true),
      fail: () => resolve(false)
    })
  })
}

module.exports = { confirmCommentLogin }
```
