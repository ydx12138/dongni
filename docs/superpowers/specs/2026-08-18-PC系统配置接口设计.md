# PC 系统配置接口设计

## 1. 目标

为 PC 端网站管理页面提供系统配置的读取和修改能力，支持控制注册、分类、我的页面、评论功能，并配置网站名称和我的页面资料。

本次只涉及 PC 端和 `blog` 后端，不涉及微信小程序。

## 2. 配置项

配置存储在 `setting` 键值表中，每个 `key` 只能有一条记录。

| key | 类型 | 默认值 | 用途 |
| --- | --- | --- | --- |
| `register_enabled` | bool | `true` | 是否允许注册 |
| `categories_enabled` | bool | `true` | 是否展示分类页面 |
| `profile_enabled` | bool | `true` | 是否展示我的页面 |
| `comments_enabled` | bool | `true` | 是否允许发表评论 |
| `site_title` | string | `懂你` | 前台网站名称 |
| `profile_github` | string | 空 | 我的页面 GitHub 地址 |
| `profile_email` | string | 空 | 我的页面 Email |
| `profile_avatar` | string | 空 | 我的页面头像地址；为空时由前端使用本地默认头像 |

布尔值在数据库中统一保存为字符串 `true` 或 `false`。配置缺失时，服务层使用上述默认值，不因旧数据库缺少配置而报错。

## 3. 接口

### 3.1 前台读取配置

```http
GET /api/settings/site
```

无需登录。返回 `models/vo/SiteSettingVO`，只返回前台可见配置，不返回数据库主键和内部时间字段。

响应数据：

```json
{
  "register_enabled": true,
  "categories_enabled": true,
  "profile_enabled": true,
  "comments_enabled": true,
  "site_title": "懂你",
  "profile_github": "https://github.com/example",
  "profile_email": "example@qq.com",
  "profile_avatar": ""
}
```

### 3.2 管理端读取配置

```http
GET /api/admin/settings/site
```

需要管理员 JWT。返回内容与前台接口相同，可额外返回最后修改时间，供后台展示配置状态。

### 3.3 管理端更新配置

```http
PUT /api/admin/settings/site
```

请求体使用 `models/dto/UpdateSiteSettingRequest`：

```json
{
  "register_enabled": true,
  "categories_enabled": true,
  "profile_enabled": true,
  "comments_enabled": true,
  "site_title": "懂你",
  "profile_github": "https://github.com/example",
  "profile_email": "example@qq.com",
  "profile_avatar": "https://example.com/avatar.jpg"
}
```

服务层校验：

- `site_title` 去除首尾空格后不能为空，最多 40 个字符。
- GitHub 和头像地址可以为空；非空时必须是 `http` 或 `https` URL。
- Email 可以为空；非空时必须符合邮箱格式。
- 四个开关必须是 JSON 布尔值。

Repository 在一个事务中按 `key` 批量新增或更新，避免保存一半时产生不一致状态。

## 4. 分层职责

- `handler`：绑定请求 DTO、调用 service、使用项目统一响应格式。
- `service`：组装配置、执行默认值和格式校验、判断功能是否开启。
- `repository`：封装 `setting` 表的查询和事务 upsert，禁止在 service 或 handler 中直接操作数据库。
- `models/dto`：管理端更新请求模型。
- `models/vo`：前台和管理端响应模型。
- `pkg/code/code.go`：新增“功能未开启”业务响应码。

推荐新增方法都使用中文注释，说明用途、参数和返回值。

## 5. 功能开关接入

- 注册关闭时，注册验证码和注册接口均返回“功能升级中”。
- 分类关闭时，前台不展示分类入口；分类页面被直接访问时也返回首页或关闭提示。
- 我的页面关闭时，前台不展示我的入口；页面被直接访问时也返回首页或关闭提示。
- 评论关闭时，仍允许查看已通过评论，但禁止创建评论并返回“评论功能暂未开放”。

前端启动时请求公共配置，并同步到网站名称、导航、我的页面和评论区域。配置读取失败时使用前端原有默认值，避免首页无法渲染。

## 6. 错误处理

沿用项目统一响应结构，不在 handler 中写业务魔法数字。至少使用以下错误类型：

- 参数校验失败：复用 `BadRequest`。
- 管理员未登录或无权限：复用现有鉴权响应码。
- 功能关闭：新增 `FeatureDisabled`。
- 数据库或配置读取失败：复用 `InternalError`。

## 7. 验证范围

- 配置表能够通过 `AutoMigrate` 正常创建或更新。
- 公共接口在无配置记录时返回完整默认值。
- 管理端可以读取并全量保存配置。
- 非法网站名称、邮箱、URL 会被拒绝。
- 注册、分类、我的页面、评论开关分别生效，互不影响。
- 前端配置读取失败时仍能使用默认界面。
