# PC 邮箱注册默认头像实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 PC 邮箱验证码注册的新用户使用配置文件中的默认头像。

**Architecture:** 在 Service 层增加纯函数 `BuildEmailUser`，负责校验头像地址并构造用户模型；`Register` 在密码哈希完成后读取 `config.Cfg.OssConfig.DefaultAvatar` 并调用该函数。微信登录、小程序与历史用户数据均不在范围内。

**Tech Stack:** Go、Gin、GORM、Go 标准测试。

```go
func TestBuildEmailUserUsesConfiguredAvatar(t *testing.T) {
    user, err := BuildEmailUser("user@example.com", "hashed-password", "小26", "https://example.com/default.jpg")

        t.Fatalf("BuildEmailUser returned error: %v", err)
```


并新增：

```go
func BuildEmailUser(email, password, nickname, avatar string) (models.User, error) {
    avatar = strings.TrimSpace(avatar)
    if avatar == "" {
        return models.User{}, ErrDefaultAvatar
    }
    return models.User{
        Email: email,
        Password: password,
        Avatar: avatar,
        Nickname: nickname,
    }, nil
}
```
