# 微信小程序博客实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成可浏览、匿名点赞、微信登录后评论的博客微信小程序，并在现有 Go 后端实现安全的微信身份登录。

**Architecture:** Go 后端新增微信会话客户端，通过接口注入以便用 `httptest` 验证 code2Session 行为。用户表增加唯一的 `wechat_openid`，首次登录生成内部邮箱与随机密码后复用既有 JWT 和评论鉴权。小程序用原生页面、统一请求层和本地 token 存储调用原有 API。

**Tech Stack:** Go、Gin、GORM、Redis、MySQL、微信小程序原生框架、`towxml` Markdown 组件。

```go
func (r *Repository) GetUserByWechatOpenID(openID string) (models.User, error) {
    var user models.User
    return user, r.db.Where("wechat_openid = ?", openID).First(&user).Error
}
```

`WechatLogin` 查询用户；未找到时调用 `BuildWechatUser` 和 `CreateUser`；禁用用户返回 `ErrUserDisabled`；正常用户复用 `GenerateUserToken`、`SaveRefreshToken`，返回与邮箱登录相同的 token 字段。内部邮箱格式为 `wechat-<openid>@wechat.local`，密码为 bcrypt 哈希的随机 32 字节值，昵称为“微信用户”加 6 位随机字符。
